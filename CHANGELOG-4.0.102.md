# RavRadar 4.0.102

## Aktiv routing vises entydigt
- Når automatisk routing er aktiv, vises de automatisk valgte vandstandskilder grønt.
- Når administratoroverride er aktivt, skjules de grønne automatiske markører, og kun de aktive administratorvalg vises rødt.
- Den lilla kategori “begge valg” er fjernet fra kort og signatur.
- Samme kilde kan ikke længere stå både som primær og sekundær; dubletter samles til én kilde med 100 % vægt.

## Bevidst uændret
- Automatisk stationsudvælgelse og topologisk routing.
- Afstandsinterpolationens matematik.
- DMI-hentning, observationsstatus og prognosepunkter.
- RavScore, Aktuelt bedste områder, femdøgnsprognose og vandstandstabellen.
- Supabase-lagring og administratoroverride i produktionskæden.
