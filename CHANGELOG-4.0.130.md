# RavRadar 4.0.130

## Privat GeoDanmark source-QA

- Gemmer den centralt effektive delmængde af de ni pilotzoner i det private geometriartifact.
- Sammenholder nuværende kystlinjer med GeoDanmark `Kyst` og måler længde, fragmentering, nærhed og stikprøveafstande.
- Registrerer havne, vandløbsender, høfder, klit og skrænt som score-neutral reviewkontekst.
- Genererer tre private QA-kort for Blåvand/Rømø, Limfjorden og Lolland/Falster.
- Stopper den planlagte blind-snapping: lokal QA flaggede 9/9 zoner og kræver klassificerede delstrækninger og eksplicit konfliktreview.

## Ikke ændret

- Ingen aktiv zone, centralt gemt administratorværdi, RavScore, produktionsdata eller offentlig Pages-fil ændres af piloten.
