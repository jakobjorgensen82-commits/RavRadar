# RavRadar 4.0.141

- Tilføjer en privat score-neutral UI-gate for de to Blåvand-kystdele.
- Bevarer den aktive parent-zones eksisterende RavScore, farvede kystlinje, klikmål, tooltip og rangering.
- Private dele vises kun som neutrale stiplede reviewkonturer med tydelig “ikke aktiv”-status; delscore, scorefarve, rangering, “bedste del”, klik og tooltip er forbudt.
- Reviewet gemmes kun i det private GeoDanmark-artifact. Ingen geometri, sampling, state, admin-data, offentlig UI eller RavScore aktiveres.
- Verificeret i privat pilot #2009 og fuld produktion #2008; offentlig version er 4.0.141.
