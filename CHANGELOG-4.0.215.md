# RavRadar 4.0.215

- Tilføjer en usynlig, ikke-blokerende tæller på den offentlige RavRadar-side.
- Gemmer kun samlede dagstal for sidevisninger og browserbesøg; ingen rå besøgshændelser, IP-adresser, præcis placering eller fingerprinting.
- Tilføjer en privat adminrapport med valgt periode, dagstal og separat antal oprettede og aktive login-konti.
- Browserbesøg beskrives udtrykkeligt som browserfaner/sessioner og ikke som unikke mennesker.
- Vejrdata, historik, RavScore og den faglige model er uændrede.
- Supabase-migrationen er installeret og rolle-/endpointtestet før deploy; testtallene er fjernet igen.
