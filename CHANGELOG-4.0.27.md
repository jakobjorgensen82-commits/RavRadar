# RavRadar 4.0.27

## DMI collection-prioritering og frisk diagnostik

- HARMONIE får reserveret førsteprioritet, når DMI-vinddækningen er ufuldstændig.
- Øvrige DMI-collections prioriteres efter faktisk dækningsmangel frem for en fast marine-først-rækkefølge.
- Bulkdiagnostikken viser dækningen før kørsel og om vindreservationen var aktiv.
- Runtime-diagnostikkens version hentes nu fra package.json.
- Admin downloader runtime og conditions direkte fra netværket ved klik, så gamle objekter fra en åben side ikke eksporteres.
- Version opdateret til 4.0.27.
