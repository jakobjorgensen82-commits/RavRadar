# RavRadar 4.0.32 – ekspertregler og femdøgnsstrategi

- Open-Meteo fortsætter som intern, komponentvis udfyldning efter DMI-horisonten. Brugeroplevelsen er ens gennem fem døgn.
- Datakvalitet og kildeovergange forbliver i admin/diagnostik og vises ikke som tekniske advarsler til almindelige brugere.
- Regelværkstedet har fået fri-tekst-assistent, der omsætter ekspertudsagn til en gennemgåelig kladde.
- Assistenten genkender foreløbig vind, bølger, timer siden høj energi, jagtform og scorevirkning.
- Ingen AI-fortolket regel kan aktiveres automatisk; menneskelig gennemgang og test er obligatorisk.
- Ny regressionstest beskytter arbejdsgangen.
