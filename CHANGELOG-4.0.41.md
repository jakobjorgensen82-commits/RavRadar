# RavRadar 4.0.41

- Ny “Spørg RavRadar”-knap på forsiden og mobilvenlig ravassistent.
- Assistenten bruger valgt zone, aktuelle forhold og RavScore; sikker lokal fallback virker uden ekstern AI.
- Klar Supabase Edge Function til avanceret AI med aktive regler som fælles vidensgrundlag.
- Nyt adminmodul “Eksperter og rettigheder” med syv brede flueben.
- Rettigheden “Aktivér regler direkte” er særskilt og kan gives uden owner-godkendelse.
- SQL-opdatering til profiler, rettigheder, RLS og automatisk brugerprofil.
