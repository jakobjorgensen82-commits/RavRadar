# RavRadar 4.0.72

## Bedste tidspunkt er nu konsistent med RavScore

- Dagens aktuelle RavScore indgår nu i valget af bedste tidspunkt.
- Kun lige nu og fremtidige timer kan vælges for den aktuelle dag.
- Den højeste samlede RavScore vinder altid.
- For waders bruges lavere/faldende vandstand kun som tie-breaker ved samme RavScore.
- Visningen skriver “Lige nu”, når aktuelle forhold er dagens bedste.
- Landsprognosen og zoneprognosen bruger samme centrale udvælgelseslogik.
- Regressionstest for uoverensstemmelsen er tilføjet.
