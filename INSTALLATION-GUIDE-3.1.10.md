# Installation af RavRadar 3.1.10

Denne mappe er et færdigt Git-repository. Den indeholder både den lokale 3.1.9-historik og den commit, der lå på GitHub, samlet uden konflikt.

## Sikker fremgangsmåde

1. Luk GitHub Desktop.
2. Omdøb din nuværende lokale mappe `RavRadar` til `RavRadar-backup`.
3. Udpak denne zip, så den nye mappe hedder `RavRadar`.
4. Åbn GitHub Desktop.
5. Vælg **File → Add local repository**.
6. Vælg den nye udpakkede `RavRadar`-mappe.
7. GitHub Desktop bør vise **Push origin** og ingen mergekonflikter.
8. Klik **Push origin**.
9. Vent på GitHub Actions, og genindlæs RavRadar-siden med Ctrl+F5.

Slet først `RavRadar-backup`, når den nye version er deployet og kontrolleret.
