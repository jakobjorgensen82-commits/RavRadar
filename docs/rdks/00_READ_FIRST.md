# RDKS – læs først

RDKS er RavRadars versionsstyrede beslutnings- og videnssystem. Det bevarer historikken uden at gøre forældede idéer gældende igen.

## Læserækkefølge
1. `90_INDEX/CURRENT_TRUTH.md`
2. `90_INDEX/IMPLEMENTATION_STATUS.md`
3. `20_REQUIREMENTS/ACTIVE-REQUIREMENTS.md`
4. Relevante aktive beslutninger og kendte issues
5. Håndbogen og aktuel kode
6. Historiske chatkilder kun ved behov for begrundelse eller udviklingshistorik

Kun poster med status **AKTIV**, **IMPLEMENTERET**, **DELVIST IMPLEMENTERET** eller **PLANLAGT** kan indgå i aktuelt arbejde. Poster med status **ERSTATTET**, **FORKASTET** eller **FORÆLDET** er historik. **UKLAR** kræver afklaring.

Import af gamle chats er dokumentationsarbejde. Den giver aldrig i sig selv tilladelse til kodeændringer.
