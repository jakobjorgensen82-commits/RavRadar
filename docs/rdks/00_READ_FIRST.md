# RDKS – læs først

RDKS er RavRadars versionsstyrede beslutnings- og videnssystem. Det bevarer historikken uden at gøre forældede idéer gældende igen.

Kun poster med status **AKTIV**, **IMPLEMENTERET** eller **DELVIST IMPLEMENTERET** kan indgå i aktuelt arbejde. Poster med status **ERSTATTET**, **FORKASTET** eller **FORÆLDET** er historik.

Import af gamle chats er dokumentationsarbejde. Uklarheder registreres til afklaring og må ikke automatisk ændre programmet.
