# DEC-0007 – Admin designes til ikke-tekniske brugere

- **Status:** AKTIV

Felter skal forklares i almindeligt dansk med eksempler, konsekvens og validering. Regelbyggeren skal være guidet, geografiske områder skal kunne vælges uden zone-ID'er, og avancerede tal som prioritet skjules bag forståelige valg. Dialoger skal kunne lukkes sikkert med kryds, Annuller, Escape og klik udenfor.
