# DEC-0008 – Kystlinjeeditoren bevarer præcision og historik

- **Status:** AKTIV

Præcisionsmarkøren bevares. Kortnavigation er et supplerende værktøj. Editor skal understøtte glatte lokale krumninger, stabil lagring, deaktivering/genaktivering af kystdele og rollback. Kunstige havne/moler må ikke diktere den naturlige kystretning.
