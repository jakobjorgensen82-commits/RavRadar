# DEC-0010 – Historiske chats importeres uden automatisk genimplementering

- **Status:** AKTIV

Gamle chats analyseres kronologisk og klassificeres. Mål kan stadig være gyldige, selv om en gammel teknisk løsning er forældet. Ved konflikt eller uklarhed markeres posten som ERSTATTET, FORKASTET, FORÆLDET eller UKLAR. Import er dokumentationsarbejde og ændrer ikke produktionskode uden en aktuel beslutning.
