# DEC-0011 – Håndbogen er en levende ekstern og intern reference

- **Status:** AKTIV

Håndbogen skal løbende forklare formål, arkitektur, data, score, oceanografi, sedimentantagelser, admin, AI, ekspertviden, drift, begrænsninger og roadmap i klart sprog. Den opdateres automatisk ved relevante versionsændringer og må skelne mellem dokumenteret viden, arbejdsantagelser og hypoteser.
