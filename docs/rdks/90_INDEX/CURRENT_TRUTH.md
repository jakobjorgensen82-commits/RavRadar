# Current truth

- DMI er autoritativ datakilde. Fallback må ikke skabe timevise kildeskift.
- Kendte DMI-stationer bevares i registeret med livscyklusstatus; de skjules ikke blot, fordi de ikke leverer i en enkelt kørsel.
- Automatisk stationsrouting må kun bruge stationer med dokumenteret leveringshistorik og må ikke bruge stationer markeret som ikke-leverende.
- Nye stationer skal opdages, observeres og først derefter kunne indgå automatisk.
- Administratoren skal tydeligt kunne se automatisk valg, override, stationens status og leveringshistorik.
- Gamle chats må kun opdatere RDKS efter konflikt- og aktualitetskontrol.
