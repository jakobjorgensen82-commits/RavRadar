# Historical candidate F comparison - bounded design

Date: 2026-08-21

## Question

What does the proposed weight change from 25/40/35 to 15/50/35 do when candidate E and candidate F receive the same measured historical wave, current and sea-level features and use the same mild physical bottleneck?

## Honest comparison boundary

The bounded historical artifact does not contain wind. Candidate D/E can still derive partial huntability, mobilisation, transport and delivery components from wave and current evidence, with reduced confidence. The active production RavScore cannot be replayed honestly because it requires wind.

The first comparison therefore measures only:

- candidate E: 25 % huntability, 40 % transport/delivery and 35 % mobilisation;
- candidate F: 15 % huntability, 50 % transport/delivery and 35 % mobilisation;
- the same candidate-E component rules and the same mild physical bottleneck for both.

It does not call candidate E the active score, does not invent historical wind and does not calibrate against finds.

## Evaluation window

Every finite sample from the wave peak through 72 hours after the peak is evaluated for both beach and waders. Event and class summaries retain only scores, component means and score-band changes. Raw weather values, raw U/V and coordinates are excluded.

## Decision use

The comparison can show whether the new weights systematically favour measured delivery over easy search conditions and whether that differs between onshore, offshore, conflicting and alongshore events. It cannot authorize production activation by itself.

The event classes describe directional relationships. A label such as `onshore-delivery` does not by itself prove strong delivery; low current speed can still produce a low transport/delivery component. The report therefore includes component means and a direct onshore-minus-offshore score check.

If a full active historical replay is still needed after this result, historical wind must be added from an authoritative source in a separate bounded step. Until then, active 25/40/35 remains unchanged.
