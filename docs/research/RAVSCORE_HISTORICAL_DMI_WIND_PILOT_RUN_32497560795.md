# Resultat af historisk DMI-vindpilot

GitHub-run `32497560795` bestod paa commit `27907f46`.

## Resultat

- 12 af 12 udvalgte haendelser fik vind.
- 970 af 972 forventede timer blev parret.
- Laveste daekning i en haendelse var 98,97 procent.
- Stoerste afstand fra godkendt kystdels-vandpunkt til valgt DMI-station var 30,49 km.
- Stoerste tidsafvigelse var 0 minutter.
- Alle fire pilotsteder havde tre haendelser.

## Sikkerhed

Artefaktet er privat og score-neutralt. Det indeholder ingen credentials, koordinater eller raa API-svar. Produktionsscore, DMI-fallback, geometri og land-/vandpunkter blev ikke aendret.

## Konklusion

Vinddaekningen er staerk nok til en afgraenset historisk afspilning af RavScores grundmotor. Resultatet kan sammenligne gammel og aktiv vaegtning samt kandidat F, men kan ikke alene kalibrere mod fund, og centralt redigerbare ekspertregler er ikke historisk afspillet.
